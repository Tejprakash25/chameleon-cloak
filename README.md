🦎 Chameleon Cloak

Real-time AI-powered background camouflage system inspired by biological adaptation — blends a subject with the wall instead of making them invisible.

⚡ Overview

Chameleon Cloak simulates adaptive camouflage using computer vision and deep learning.
It segments the foreground in real time and reconstructs the background to create a seamless blending effect.

🧠 Core Idea

Detect → Segment → Reconstruct → Blend → Render
Inspired by chameleon camouflage, not traditional invisibility cloaks.

🛠 Tech Stack

Python

OpenCV

PyTorch & TorchVision

Semantic Segmentation Models

NumPy

✨ Features

Real-time foreground segmentation

AI-based background reconstruction

Smooth pixel-level blending

💡 Why it stands out

Unlike basic invisibility cloaks, this project uses deep learning segmentation + context-aware blending, making it closer to real-world biological camouflage.
